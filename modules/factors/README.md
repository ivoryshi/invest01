# 因子实验室

当前：v0.5.1 / 迁移V0.18。以原生页面与统一API完成“定义 → 配置 → 请求 → 实际执行 → 结果/审计 → 历史查询”，不嵌入旧HTML，不调用旧回测脚本。旧项目只读；缺失数据和不支持策略不得用旧曲线冒充新结果。

## 使用链路

1. 查询内置库，或提交因子定义与子因子/指标、方向、公式、缺失值策略及使用逻辑。
2. 选择策略模板与现成数据，保存配置草案。保存本身不执行计算。
3. 检查源版本、公式revision、日期、交易规则、基准与成本；创建运行请求。
4. 显式执行请求；成功生成新结果，失败返回明确错误，不以导出资产作为回退。
5. 复核指标、账户/持仓账本、因子得分、归因闭合、敏感度、数据口径与警示；结果默认仍需研究复核。

内置库目前12族/64字段；“已登记”不是所有字段都有真实历史输入或计算映射。新增因子可持续提交/查询/修改，已保存的自建公式配置保留原revision副本，不随定义修改自动升级。

## 执行器覆盖

| 执行器 | 输入 | 真正执行的规则 | 不能推断的能力 |
|---|---|---|---|
| 旧行业兼容 | 已导出panel.json | 月度得分、TopN、换手费用 | 不等于原始日频数据重建 |
| 原始行业 | panel/bench/investable.parquet | 滞后信号、月度等权TopN、可投数与成本 | 没有完整历史披露可见性或真实ETF成交 |
| 自建行业 | 同三文件 | 白名单公式、依赖节点、方向/权重、同日z分数与真实TopN | 不执行任意用户代码，不覆盖全部论文公式 |
| 宽基定投 | broad.parquet | 月/周/双周、金额、宽基/现金固定投入、同流基准与成本 | 不支持任意自然语言交易规则 |
| A/B/C三档 | 八个Parquet文件 | A估值/趋势闸门、B轮动/持有期限与资金转A、C宏观/基差模型 | C是利率模型，不是债券真实成交或历史宏观修订库 |
| 基金横截面 | wide_today.csv | 严格同策略/频率/基准/口径分组，明确字段与筛选审计 | 不是基金历史因子轮动 |
| 基金历史篮子 | 新工作台SQLite | 手动同频/复权份额、固定新投入权重、月/周/双周、不卖出 | 不是历史择优、申赎确认或再平衡 |

参数合法性由对应执行器校验，页面可填不意味着所有组合可执行；不支持时拒绝。策略模板及默认值来自[契约](../../packages/contracts/factors.js)，支持范围由API options和执行器实现共同确定。

## 自建公式与版本

有限AST解释器在[源码](src/factor_expression.py)中实现，无eval、SQL、外部路径或用户代码执行。白名单字段绑定，有限算术及lag/rolling_mean/rolling_std/pct_change/abs/log/sqrt；后向窗口，不接受前视。最多16绑定/节点、512字符、128 AST节点、24层深度、窗口1至756。

子节点可依赖其他节点；依赖环和未知字段拒绝。零权重中间节点可用；每个正权重输出需完整有效值、至少三个有限横截面观测。使用总体标准差z分数、±3缩尾、方向及权重合成，不把缺失或零除填为0。定义/配置保存revision、executionSpec与SHA；试算仅同日定位，不生成回测或交易信号。

## 结果与诊断

结果保存配置revision、数据版本及捕获执行的主/依赖源码SHA、完整账本、现金流/持仓/得分审计、指标、警示及计算说明。曲线可能抽样用于显示，审计账本不是抽样曲线。

行业/自建行业实际重跑零费用、双交易费、TopN±1、滞后+1及自建节点权重扰动；合法边界外不强行计算，失败案例独立标为unavailable。代理风险模型使用单因子策略的同日超额收益，最多8个正输出；常数、秩不足、条件数大于1e6等拒绝系数。它是内生样本诊断，不是独立可投资因子收益或因果Alpha。

行业单位资本以跨期链接闭合终值超额；宽基、基金、三档用现金流金额逐日闭合终值差。不得与XIRR百分比相加。旧alphaReturn/smartBetaReturn等因果字段不伪填。公式、年化及风险贡献口径见[计算说明](../../docs/wiki/FACTOR-CALCULATIONS.md)。

## 数据与历史资产

基金运行时只读SQLite，不再逐次读取旧CSV。离线SHA增量导入、选定份额/基准导入、备份包/完整性核验和恢复到新文件均可手动执行；整库包尚未纳入实验冻结API，也没有自动调度或外部备份验收。数据库随当前仓库定位，旧行业/宽表/导出路径仍绑定本机。

CSV/Parquet的已支持current/冻结版本严格绑定；缺失或损坏不自动换用当前数据。基金动态选定源冻结仍待接。旧out当前13文件的逐字节副本排除Git，最新归档61条标准记录，包括严格JSON及静态表单默认值索引；静态默认值不是真实历史实验参数，HTML不执行。
