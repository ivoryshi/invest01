# 因子计算口径

本页解释实际计算，不宣称有效投资策略。不同执行器的资产、资金流、费用和日历不可混合排名。复核时以结果dataScope、账本、sourceVersions与源码SHA为准，不仅看页面标题或小数显示。

[回测工具](FACTOR-BACKTEST.md)复用下方计算口径，不另造回测引擎。预检只做验证函数和输入检查，不生成收益；结果结构审计核对保存资产的绑定/指纹存在/有限指标及已有归因闭合容差，不独立重算、不证明PIT或因果Alpha。通过时仍为review_required，不表示收益有效性已验收。

## 信号与打分

原始行业/自建行业用观测日滞后信号执行月度TopN等权；signalLagDays为1至20个观测日，不等于自然日。可投资标识、最少候选数和完整样本规则约束选择。自建每个正权重输出至少三个有效横截面观测，总体标准差z分数、±3缩尾、方向/权重合成；缺失/零除不填0。AST只允许后向完整窗口。

最新基金宽表按策略类型、实际频率、基准与口径严格同组，保存原值/得分贡献及筛选审计。不是过去各期可见的基金截面。不能用当前费率、经理、规模或持仓反填历史。

宏观可用日与指数proxy存在假设；观察日不证明真实发布日。真实披露、成分与修订史尚不完备，仍可能有前视/幸存者偏差。自建preview是同日定位，不是交易指令。

基金历史数据冻结保存的是本次选定的完整历史和源版本，不是每个历史决策日的PIT截面。profile及结果标为not_point_in_time_verified；不允许最新因子驱动历史选基。隔离回归覆盖“修改回测结束后的净值，不改变结束前账本/指标”，只证明这个固定篮子不使用未来收益观测，不证明名录、复权修订或基金选择没有幸存者/前视偏差。详见[时点协议](FACTOR-DATA.md)中的“数据时点与比较”。

## 资金、费用与收益

- 定投计划按月/周/双周生成，投入在实际执行日收盘后进入资产；新投入不赚取此前行情或现金利息。共同日历不填充；计划日缺数据可延至规则允许的首个共同日期，超范围/过大缺口拒绝。
- TWR排除外部投入，账户价值不等于单位净值。XIRR按真实日期现金流求解，年率范围-0.95至3.0、二分最多200次；无解/零时长留空并警示，不把null当0。
- 基金份额复权净值已包含日常管理等费用，不重复扣年费；模拟申购/滑点每笔单扣。固定新投入比例不意味着持仓每期再平衡，也不等于实际申赎确认份额。
- 行业/宽基/三档执行器按各自costModel扣年费/交易费。宽基基准沿用其同费用设置，基金/三档基准为同流毛指数；不能只看同benchmarkId就假定成本相同。
- 行业/代理诊断常用244年化；基金历史篮子波动按共同观测数与实际区间年数确定。Sharpe无风险利率假设为0。收益率输出为小数，页面再格式化为百分比；金额与无量纲净值分别标示。

执行器不同会保留各自年化/日历规则，不通过文档把它们改成统一值。完整公式见[industry_engine.py](../../modules/factors/src/industry_engine.py)、[dca_engine.py](../../modules/factors/src/dca_engine.py)、[fund_nav_engine.py](../../modules/factors/src/fund_nav_engine.py)、[three_bucket_engine.py](../../modules/factors/src/three_bucket_engine.py)。

## 行业单位资本归因

设rs、rb为当日策略净收益和基准收益，E为期初股票暴露，G为未扣费用毛收益，S为策略净值，B为基准净值。

```text
现金暴露      = (E - 1) × rb
行业相对选择  = G - E × rb
年费          = -当日年费 / S_prev
交易费        = -当日交易费 / S_prev
分项之和      = rs - rb
链接权重      = S_prev × B_T / B_t
全期链接之和  = S_T - B_T
```

这是事后账本拆解，不是因果择时Alpha。终值贡献不年化，月度分组仍为全期链接后的金额/单位资本贡献，不是月收益。单基准OLS含样本截距/Beta/残差、rf=0，仅用于诊断。

## 含投入的金额归因

宽基、基金固定篮子和三档设期初持仓V、现金C、策略/基准账户S/B，毛资产损益P，现金利息I：

```text
资产相对项  = P - V × rb
现金项      = I - C × rb
账户差延续  = (S_prev - B_prev) × rb
年费项      = 基准年费 - 策略年费
交易成本项  = 基准交易成本 - 策略交易成本
当日分项和  = (S_t - B_t) - (S_prev - B_prev)
全期直接和  = S_T - B_T
```

同日同额投入抵消，不计投资收益。这些是金额，不与XIRR差/TWR百分比相加；也不使用单位资本的跨期链接权重。记录每日输入、贡献、月度金额、error和errorBound。容差依据参与金额ULP和项数，保留真实误差，不用残差自动掩盖错误账本。允许合计误差1e-8内的权重先规范化，实际使用权重保存，用户配置不篡改。

## 代理多因子风险模型

仅行业/自建行业：y为净策略日超额；X为毛市场收益和各单因子策略日净超额，带截距、rf=0。列中心化/标准化后NumPy最小二乘，还原系数。至少max(20, 2×参数数)观测，常数列、秩不足、条件数大于1e6不输出独立系数。自建最多8正输出，超限保留主回测但模型拒绝，不悄悄减少列。

组件包括市场、proxy:因子、sample_intercept、model_residual，逐日相加为y；用行业链接权重闭合终值诊断。年化跟踪方差=244×Var(y, ddof=1)，组件贡献=244×Cov(component,y,ddof=1)，有符号且可能负；总和闭合方差。

代理来自同一面板/规则，具有内生性。样本截距不是投资Alpha，残差不是无风险超额，组件不是已验证可投资Smart Beta。alphaReturn/smartBetaReturn/residualReturn等因果结果不伪填。

## 敏感度与误差

行业/自建行业在同一捕获数据下实际重跑零费用、双交易费、TopN±1、滞后+1；自建另减首个正输出权重10%。超过合法边界不强行重跑，单案例失败unavailable并保留error，主结果不丢失；不是证明参数稳健或样本外预测。

误差须区分：数值闭合误差、数据缺口、模型proxy/披露/幸存者偏差、交易成本/流动性假设、事后参数选择。通过代数闭合只证明计算一致，不消除数据和模型误差。完整逻辑与未知项随结果保留，不从旧导出缺失参数补造结论。
