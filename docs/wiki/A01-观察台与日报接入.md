2026-09-16；实现v0.2.0，验收记录见records/REVIEWS.md。本批不是所有模块整合完成。

## 复用结果

原观察台build/expand/app/complete/daily/shell与逻辑测试完整复制到modules/observatory/src。保留13个页面、6个信用面板、16指数、10风格、20信号组、40宏观指标、38公司、5传导链、7叙事及证据/导入导出/版本逻辑。

6份现有真实日报JSON、原版HTML与已有render-history原样复制到modules/daily/public/reports，catalog原快照位于modules/daily/data。A01阶段日报曾与观察台共享前台引擎作为过渡复用；A02已拆分为日报自身归档阅读器与catalog构建，不再依赖观察台构建产物。

复制来源和原始哈希见[清单](records/copy-manifest-A01.json)。原日报render模板和CSS保存在modules/daily/legacy，发布入口已明确禁止直接执行；真实定时生产仍在旧任务，未启用第二个发布者。新站目录不会自动同步旧自动化新报告，页面明确为快照。

## 运行

在新项目根目录执行：

```sh
npm run build
node modules/daily/src/build.js
npm run check
npm test
npm run test:observatory
npm start
```

统一工作台默认端口4311。可分别运行npm run start:observatory（4312）、npm run start:daily（4313）；都固定监听127.0.0.1，可用PORT换端口。独立启动不依赖工作台HTTP进程；观察台与日报分别构建，日报不由观察台脚本复制覆盖。

## 必要适配

- 移除旧绝对输出路径与旧目录扫描，构建只读取新副本的配置/代码/归档。
- 明确/modules/observatory/与/modules/daily/路径及尾斜线；固定资源目录不暴露源码、内部catalog或legacy发布器。
- 应用JS/CSS外链；归档HTML维持原字节，通过限定脚本哈希兼容原脚本。必要内联样式仅用于模块路由，工作台外层策略不放宽。
- 修复securityTemplate未定义id导致对象模板下载失败。
- 分开补刊/提前/周末版，历史测试不再写死1份日报。
- 日报只读档案不随观察台演示切换成为虚构数据。

## A02更新 · 2026-09-17

- 工作台不再使用iframe承载模块；`apps/web/module-loader.js`将模块HTML/JS/CSS原生挂载到工作台内容区，并用Shadow DOM隔离模块样式与DOM查询。切换模块时清理事件监听、抽屉内容和滚动锁定。
- 外层工作台使用`workbench-main`、`workbench-nav`、`workbench-content`，避免与观察台自身`main`、`nav`、`drawer-root`等固定ID冲突。
- 日报前端改为独立归档阅读器，读取`modules/daily/public/catalog.json`，支持日期、AM/PM、关键词筛选、详情、原始HTML和JSON入口；原始归档HTML/JSON不改字节。
- API新增按模块命名空间的v1接口：`/api/modules/daily/v1/reports`、`/api/modules/daily/v1/reports/:archiveKey`、`/api/modules/observatory/v1/config`、`/api/modules/observatory/v1/sources`。
- 研究生产首批接入`/api/modules/research/v1/skills`、`/workflows`和`/artifacts`，来源为旧项目只读索引；不启动旧Express服务、Skill执行器、Longbridge、AkShare或监控任务。

## 用户研究记录

新浏览器键workbench01-observatory-v1，避免同域旧键串用。旧file地址、旧端口及独立模块端口的localStorage不会自动转移。请在原观察台导出研究记录，再在新观察台的数据与来源页恢复；保留旧导出文件。复制源码不等于迁移浏览器个人记录。

新副本仍是浏览器本地保存，不是服务端数据库或跨设备同步。现有真实行情缺口保持为空，演示显式标注。
