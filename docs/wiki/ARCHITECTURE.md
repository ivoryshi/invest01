# 架构基线

## 当前实现 · v0.5.6

本节是当前事实，下方N01/V0.2为历史方案。Node原生HTTP提供明确静态白名单及版本化API，浏览器ES Modules原生挂载，观察台模块用Shadow DOM隔离；不使用iframe或嵌套旧页面。API按观察台/研究/日报/因子命名空间划分，七入口中知识/组合/Lance核心仍待迁入，日报生产暂停。

因子定义/配置/请求/结果保存在本机var JSON；显式执行请求捕获Python主/依赖源码字节和SHA，再只读已有数据执行，写入新的结果与审计。不是后台队列或多用户事务服务。行业/自建行业、宽基、三档和基金篮子执行器各有实际口径，候选登记和旧结果显示不等于已执行。

回测工具/API/CLI与项目内Skill复用六类执行器，含归档PE正式冻结执行；预览只读。只读预检绑定保存配置、冻结、验证/计算及调用代码，显式确认才执行，完成凭证复用、旧入口禁止受保护请求重跑。全部因子写请求有单进程互斥，重叠409；多个服务器进程不共享锁，请求/结果两JSON仍非事务，孤立受保护结果拒绝盲目重试。v0.5.6补服务异常清理、单面板失败隔离与工作区代次保护，不把工具扩成后台调度或架构改造。详情见[回测流程](FACTOR-BACKTEST.md)。

基金历史使用新工作台SQLite，单源离线导入事务与只读计算事务；原CSV/fof.db只读。选定基金完整历史/名录与一个基准从读事务导出独立SQLite，沿用已有snapshot/config/request/result链路；内容、选择、捕获源码纳入身份，执行从SHA核验的同字节内存数据库读取。CSV/Parquet冻结和旧导出不可变档案也按内容身份保存；整库备份通过SQLite在线备份，恢复新文件不自动换库。沿用标准库/既有工具，无新数据库服务或依赖。

输入可复现和PIT历史可得性分开。现有净值没有availableAt，profile/结果明确标为未通过PIT验证且不支持历史因子选基；最新宽表不用于过去决策。工具和回测Skill落实[数据时点协议](FACTOR-DATA.md)中的“数据时点与比较”，PIT要求被阻止，不通过冻结时间或代理滞后伪造披露证据。

PostgreSQL/对象存储/认证/后台workers仅为后续方向，没有安装或实现。现有绝对来源路径仍部分本机绑定；当前相对化的是工作台基金数据库，不能声称全项目已可无数据跨机器运行。完整接口/计算/数据边界见[API](FACTOR-API.md)、[计算](FACTOR-CALCULATIONS.md)、[数据](FACTOR-DATA.md)、[安全](../../SECURITY.md)。

## 历史基线（保留原阶段说明）

延续已讨论的模块化 API、研究任务执行器、Python 因子执行器、PostgreSQL 和对象存储方向。它们是目标架构，尚未安装或实现；新项目的具体工程依赖与落地顺序在 N01 确认。

目录预留：apps/web 页面、apps/api 接口、workers/research 研究任务、workers/factors 因子任务、packages/contracts 公共契约、adapters 数据服务适配、tests 验证、docs/wiki 文档、var 本地运行产物。

数据接入需登记供应商、工具权限、指标定义、频率、来源时点与取数时间。缺失数据不填零；演示数据必须显式标记。TradingView、Longbridge 等能力逐项核验，不将工具可见视为数据权限可用。

每日摘要以规范化报告数据为渲染来源，保留修订版本。宏观到公司证据与反证需能回溯；因子实验保留数据、股票池、口径和引擎版本。

旧项目当前仅作参考，未复制代码，也未迁移历史数据。未来引入模块须登记原始路径、提交或文件哈希、复制时间、目标路径、适配修改及检查结果。

## N01 实施决策

先采用 Node 原生 HTTP 和静态 ES Module 页面验证独立运行与接口边界，无第三方依赖。相较立即引入完整前后端框架，此阶段便于建立可复现启动和测试基线；复杂组件、认证和持久化到对应批次确定，不以本骨架替代最终技术架构。API 仅公开明确列出的资产，固定本机监听，不提供数据库或外部 MCP 调用。
